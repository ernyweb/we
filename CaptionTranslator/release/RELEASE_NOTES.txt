────────────────────────────────────────────────────────────────

FOREGROUND_SERVICE        : Background operation
FOREGROUND_SERVICE_MIC    : Microphone in background

📱 Installation Instructions
────────────────────────────────────────────────────────────────
1. Download: caption-translator-v1.0.0.apk
2. Enable: Settings → Security → Unknown Sources
3. Install APK
4. Grant microphone permission
5. Grant overlay permission
6. Configure languages
7. Toggle service ON
8. Enjoy translated captions!

⚙️ Configuration Options
────────────────────────────────────────────────────────────────

Caption Size    : 12sp - 42sp (adjustable)
Position        : Bottom-center (100px from bottom)
Auto-hide       : 5 seconds after display
Background      : Semi-transparent black (#CC000000)
Text Color      : White with shadow

🚀 Performance
────────────────────────────────────────────────────────────────
Battery Usage  : ~3-5% per hour (optimized)
Memory Usage   : ~80 MB (includes ML models)
Latency        : 500ms - 2 seconds (speech → caption)
Accuracy       : 85-95% (depends on audio quality)
Offline Mode   : Yes (after model download)

⚠️ Known Limitations
────────────────────────────────────────────────────────────────
• First translation requires internet (model download)
• Each language pair downloads ~30-50 MB
• Caption position fixed (bottom-center only)
• Auto-hide timeout fixed (5 seconds)
• Single speaker recognition (no multi-speaker separation)
• Background noise may affect accuracy

🔧 Troubleshooting
────────────────────────────────────────────────────────────────
Problem: No captions appearing
Fix: Check permissions → Toggle service OFF/ON

Problem: Wrong language detected
Fix: Set specific source language (not Auto Detect)

Problem: Service stops randomly
Fix: Disable battery optimization for app

Problem: Translation too slow
Fix: Download models → Use offline mode
