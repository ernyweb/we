# Live Caption Translator v2.0.0

🌍 **Real-time Speech Translation App**

## ✨ Features

- 🎤 **Live Speech Recognition** - Continuous microphone listening
- 🌐 **Multi-language Translation** - English, Turkish, Russian, Spanish
- 📱 **Overlay Captions** - Floating subtitles over any app
- 🔐 **Secure Translation** - Self-hosted VPS server with HMAC-SHA256
- 🎨 **Modern UI** - Clean, intuitive interface
- ⚡ **Fast & Reliable** - 900+ word dictionary

## 📦 Installation

1. Download [LiveCaptionTranslator-v2.0.0.apk](LiveCaptionTranslator-v2.0.0.apk)
2. Enable "Install from unknown sources"
3. Install and grant permissions:
   - Microphone access
   - Display over other apps

## 🎯 Usage

1. Select source and target languages
2. Toggle the service ON
3. Grant required permissions
4. Start speaking - captions will appear automatically!
